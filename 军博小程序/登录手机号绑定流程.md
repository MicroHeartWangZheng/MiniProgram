# 小程序登录接口 `smallProgramLogin` 返回 `100` 后的手机号绑定流程

## 1. 进入登录页

登录页加载时，会在 `onLoad` 中调用：

```js
app.userLogin()
```

也就是先走一次小程序自动登录流程。

## 2. 调用微信登录

`app.userLogin()` 内部会先调用：

```js
wx.login()
```

获取微信临时登录凭证 `code`。

## 3. 请求后端登录接口

拿到微信 `code` 后，请求后端接口：

```js
saas/smallProgramLogin
```

完整接口形式类似：

```text
sw-saas-cloud/saas/smallProgramLogin?code=微信code&appId=小程序appId
```

## 4. 判断 `smallProgramLogin` 返回结果

如果接口返回：

```js
code == 200
```

表示登录成功，会保存登录态：

```js
globalData.authorizationc = res.data.authorizationc
globalData.openId = res.data.openid
globalData.encryptKeyVersion = res.data.version
```

如果接口返回：

```js
code == 100
```

表示微信登录成功，但当前用户还没有绑定手机号，需要进入手机号授权绑定流程。

此时会解析 `res.msg`：

```js
var data = JSON.parse(res.msg)

openid = data.openid
openIdType = data.openIdType
session_key = data.session_key
```

这些值会临时保存起来，后面绑定手机号时使用。

## 5. 用户勾选隐私协议

登录页中的“手机号快捷登录”按钮，默认不是微信手机号授权按钮。

只有用户勾选：

```text
我已阅读并同意《隐私协议》
```

之后，代码才会把按钮的 `openType` 设置为：

```js
"getPhoneNumber"
```

也就是：

```js
openType = "getPhoneNumber"
```

这样用户点击按钮时，微信才会弹出手机号授权窗口。

如果没有勾选隐私协议，点击按钮只会提示：

```text
请先同意《隐私协议》
```

## 6. 用户授权手机号

用户点击“手机号快捷登录”后，会触发：

```js
onGetPhoneNumber()
```

如果用户拒绝授权，会弹窗提示：

```text
拒绝获取手机号将无法使用小程序进行预约
```

如果用户同意授权，会拿到微信返回的：

```js
encryptedData
iv
```

然后组装绑定手机号参数：

```js
{
  encryptedData: encryptedData,
  iv: iv,
  openId: openid,
  openIdType: openIdType,
  sessionKey: session_key,
  appId: wx.getAccountInfoSync().miniProgram.appId
}
```

## 7. 请求手机号绑定接口

组装好参数后，调用：

```js
smallProgramLoginByPhone(data)
```

对应后端接口：

```text
saas/smallProgramLoginByPhone
```

返回后继续判断：

### `code == 200`

表示手机号绑定成功，同时登录成功。

会保存全局登录态：

```js
globalData.authorizationc = res.data.authorizationc
globalData.openId = res.data.openid
globalData.encryptKeyVersion = res.data.version
```

然后返回上一页，或者跳转到登录前传入的目标页面。

### `code == 310`

表示当前用户无法使用此微信小程序。

会提示：

```text
无法使用此微信小程序
```

### 其它 `code`

表示绑定手机号失败。

会弹窗提示：

```text
绑定手机号失败，接口返回的错误信息
```

## 总结

`smallProgramLogin` 返回 `100` 的含义是：

```text
微信登录已经成功，后端已经拿到了 openid 和 session_key，
但用户还没有绑定手机号，所以不能直接完成登录。
```

后续必须通过微信手机号授权，调用：

```text
saas/smallProgramLoginByPhone
```

完成手机号绑定后，才会真正写入 `authorizationc` 登录态。
